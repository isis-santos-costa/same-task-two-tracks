The Data Profiling reviewed 60 customer records on completeness and quality. Missing values were detected in: customer_id. No outliers found.

Core profile boils down field information by class:

  • For numerical fields (age, purchase_amount, signup_date), it informs on central tendency and dispersion via core distribution (min/max: q0/100, median: q50, interquartile ends: q25/75), average, and—for non-date fields—outliers range and count, plus, in the Data Profiling v3+, a robust coefficient of variation [1].

  • For low-cardinality fields (loyalty_tier, account_active)—with up to 10 categories— it breaks down the values count for each category, shedding light onto consistency, distribution, and balance.

  • For high-cardinality fields (customer_id, email, state), the Core profile is given by uniqueness, as a measure of distinctiveness across entities and of identifier integrity. Primary identifiers (IDs) are expected to be 100% unique. Business identifiers may tolerate a limited % of reuse, e.g., phone number. There are also high-cardinality fields for which uniqueness is expected to be lower, like state.

The Core profile supports anomaly detection such as out-of-bound values or invalid ages or dates.
Numerical field distributions (in v3+) complement this.
